# Drift Doctor

A comprehensive ML monitoring and drift detection system with an AI-powered chatbot assistant.

## Project Structure

- **data/**: Data scraping, raw data, processed data, and drift detection data
- **ml/**: Machine learning models, drift detection, training, and validation
- **agent/**: AI agent with LLM integration for drift explanation
- **backend/**: FastAPI server with REST endpoints and task scheduling
- **frontend/**: React frontend with real-time WebSocket updates
- **shared/**: Shared utilities, schemas, and configurations
